# Run quota-balanced rotation as a server-owned state machine

Quota-Balanced Rotation runs in the dashboard server, remains off by default, and operates independently of an open browser. It requires `fill-first` routing, disabled session affinity, healthy response logging, singleton controller ownership, and fresh recognized weekly evidence. The controller evaluates each new observation once, changes only future routing, permits best-effort five-percentage-point balancing, records Pending Rotation before mutation, confirms a new Routing Target from later identity-bound normal traffic, supports one-request Provisional Reset Candidates without Quota Probes, and enters Manual Hold or a recorded pause when operator intent, configuration, identity, evidence, or recovery safety becomes uncertain.
